# Generated Results

This directory contains figures and tables generated by
`notebooks/CHE1147_project.ipynb`.

Results should be regenerated by running the notebook from top to bottom
with the documented environment.

Model selection uses development-set cross-validation RMSE.
Test-set results are used for final evaluation and MW-group analysis.

Saved model files are excluded from this repository because they can be
regenerated by running the training code.
